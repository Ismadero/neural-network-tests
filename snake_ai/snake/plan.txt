PLAN: SNAKE AI CON DEEP Q-NETWORK (DQN) + CNN
===============================================

OBJETIVO
--------
Entrenar una red neuronal con deep learning (backprop) para que juegue Snake
automaticamente. Se usara una CNN dentro de un agente DQN.


ARQUITECTURA GENERAL
--------------------
- Algoritmo : Deep Q-Network (DQN)
- Red       : CNN (la grilla 15x15 es naturalmente una imagen)
- Framework : PyTorch (recomendado) o TensorFlow


REPRESENTACION DEL ESTADO
--------------------------
La grilla se convierte en un tensor con canales separados (como imagen RGB):
  - Canal 0: posicion del cuerpo de la serpiente
  - Canal 1: posicion de la cabeza
  - Canal 2: posicion de la comida
Dimension resultante: (3, 15, 15)


ACCIONES
--------
3 acciones relativas a la direccion actual:
  - 0: seguir recto
  - 1: girar a la izquierda
  - 2: girar a la derecha
(Evita que la red considere ir en sentido contrario, que es muerte inmediata)


REWARDS
-------
  - Comer comida : +10
  - Morir        : -10
  - Cada paso sin comer: -0.1 (penaliza quedarse quieto o en circulos)


COMPONENTES DQN
---------------
  1. CNN (Q-network)     : recibe el estado, predice Q-value por accion
  2. Target network      : copia de la Q-network, se actualiza cada N pasos
                           para estabilizar el entrenamiento
  3. Experience replay   : buffer que guarda (estado, accion, reward, estado_siguiente)
                           y entrena en batches aleatorios
  4. Epsilon-greedy      : exploracion aleatoria al inicio, va bajando con el tiempo


CAMBIOS NECESARIOS AL CODIGO ACTUAL
-------------------------------------
  1. Modo headless en Game: poder correr sin Screen para entrenar rapido
     - Pasar un flag al constructor: Game(render=False)

  2. Control externo: que run() acepte una accion en lugar de leer el teclado
     - Nuevo metodo: game.step(action) -> (estado, reward, done)

  3. Metodo get_state(): retorna el tensor (3, 15, 15) con la grilla actual

  4. Metodo get_reward(): retorna el reward del paso actual


ORDEN DE IMPLEMENTACION SUGERIDO
----------------------------------
  1. Adaptar Game para control externo (headless + step())
  2. Implementar get_state() como tensor
  3. Definir la arquitectura CNN en PyTorch
  4. Implementar el buffer de experience replay
  5. Implementar el loop de entrenamiento con DQN
  6. Entrenar y evaluar


ARCHIVOS NUEVOS ESPERADOS
--------------------------
  - agent.py      : logica del agente DQN (epsilon, replay buffer, entrenamiento)
  - model.py      : definicion de la CNN en PyTorch
  - train.py      : loop principal de entrenamiento
  - evaluate.py   : correr el agente entrenado con render=True para verlo jugar
